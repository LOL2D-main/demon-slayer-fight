## 🥋 2D Fighting Game

A browser-based 2D fighting game built with HTML5 Canvas, JavaScript, and CSS. This game supports **two players**, real-time health tracking, and custom controls for movement and attack.

---

### 🎮 Features

* Two-player local fighting game
* Health bars with real-time updates
* Countdown timer
* Game result overlay (win, lose, tie)
* Responsive and styled game HUD
* Player controls for movement and fighting
* Built using vanilla JavaScript and HTML5 Canvas

---

### 🧠 How to Play

**Player 1 Controls:**

* Move: `W` (Jump), `A` (Left), `D` (Right)
* Attack: `Q`, `Space`, `E`, `R`

**Player 2 Controls:**

* Move: `Arrow Up` (Jump), `Arrow Left`, `Arrow Right`
* Attack: `Arrow Down`, `<`, `>`, `/`

---

### 🛠️ Tech Stack

* **HTML5** – Structure & Canvas
* **CSS3** – Styling and layout
* **JavaScript (ES6)** – Game logic, animation, interaction
